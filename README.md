# First PR Practice

This repository is a small sandbox for practicing the GitHub pull request workflow:

1. Create a branch
2. Make a small change
3. Open a pull request
4. Merge it

## What this repo does

Nothing — it's just a place to practice. Feel free to fork it or use it as a reference for how a simple PR is structured.

## Goals

- Learn how to open a PR from the command line
- Get comfortable with the branch -> commit -> push -> PR loop
- Receive feedback on a change through the PR review flow
